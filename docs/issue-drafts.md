# Черновики задач для GitHub Projects

Эти тексты нужно перенести в проект команды и привязать Story к Epic. Номера и ссылки пока не существуют.

## Epic

**Название:** `[Epic] Настроить пространство команды для ДЗ №1`

**Описание:** Создать связанное учебное пространство GitHub Projects → Wiki → репозиторий. Результат: Epic и дочерняя Story, Wiki со ссылками, ветка Story, коммит, PR и merge в `master`.

**Критерии готовности:**

- Проект команды доступен всем подтверждённым участникам.
- Story связана с этим Epic.
- Wiki содержит ссылки на обе задачи.
- Репозиторий и PR доступны по ссылкам из формы сдачи.

## Story

**Название:** `[Story] Добавить описание командного процесса в репозиторий`

**Описание:** Как участник учебной команды, я хочу видеть в репозитории короткое описание сквозного процесса, чтобы понимать, как задача переходит в ветку, PR и документацию.

**Критерии приёмки:**

- Story привязана к Epic.
- От `master` создана ветка с номером Story.
- В ветке добавлено или улучшено описание процесса.
- Изменение отправлено в GitHub и слито через Pull Request в `master`.
